async/ is a directory which contains tutorials about the use of fetch() or 
  asynchronous callback functions, also refered to as ajax in older JS speak
  but without the use of XMLHttpRequests this terminology is rendered obselete. 

weather_app/, the subdirectory of async/ is a folder which is dedicated
  to the creation of a website application using async logic to call a 
  public API: https://simplyjavascript.com/projects/weather-app.html
