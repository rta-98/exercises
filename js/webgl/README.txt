webgl/ hosts a number of tutorials relating to the implementation of the
  JS library WebGL. 

threejs/ is a subdirectory contained in webgl/ which hosts tutorials relating
  ot the implementation of three.js, a JS library built on top of WebGL which 
  simplifies much of the lower-level logic/GPU-plumbing
